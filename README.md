# QuranPdfReader (Android)

یہ ایک سادہ اینڈرائیڈ ایپ ہے جس میں صرف `quran.pdf` دکھائی جاتی ہے۔

## فیچرز
- `app/src/main/assets/quran.pdf` سے پی ڈی ایف لوڈ ہوتی ہے۔
- پی ڈی ایف میں موجود لنکس سپورٹ ہوتے ہیں (PDF viewer library کے ذریعے)۔
- آخری پڑھے گئے صفحے سے دوبارہ اوپن ہوتی ہے۔
- لاسٹ ریڈ ہسٹری میں **5 صفحات** محفوظ ہوتے ہیں اور ہر صفحے کی ریڈ کاؤنٹ **زیادہ سے زیادہ 7** تک رکھی جاتی ہے۔

## اپنی اصل فائل لگانا
ابھی `quran.pdf` ایک placeholder ہے۔ اپنی اصل قرآن فائل اسی نام سے یہاں رکھیں:

- `app/src/main/assets/quran.pdf`

## رن کرنے کا طریقہ
1. Android Studio میں فولڈر اوپن کریں۔
2. Gradle sync کریں۔
3. Emulator یا device پر run کریں۔
